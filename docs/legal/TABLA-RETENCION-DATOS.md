# Tabla de retención y disposición de datos

Esta tabla es un modelo operativo. Los plazos definitivos deben aprobarse con base en obligaciones educativas, archivo, defensa de derechos y el manual institucional.

| Categoría | Retención propuesta | Disposición final | Responsable |
|---|---|---|---|
| Cuenta de usuario activa | Mientras exista vínculo | Desactivar; conservar auditoría necesaria | Administrador |
| Cuenta inactiva | `[DEFINIR PLAZO]` | Supresión o anonimización | Administrador |
| Datos básicos del estudiante | Mientras exista vínculo + `[DEFINIR]` | Archivar, anonimizar o suprimir según obligación | Institución |
| Reportes y actuaciones de convivencia | `[DEFINIR SEGÚN ARCHIVO Y MANUAL]` | Archivo restringido o supresión autorizada | Coordinación |
| Alertas | Mientras exista seguimiento + `[DEFINIR]` | Cerrar y anonimizar si procede | Coordinación |
| Salidas | `[DEFINIR]` | Supresión o archivo restringido | Coordinación |
| Notificaciones | `[DEFINIR]` | Supresión o anonimización | Administrador |
| Evidencias | Mientras sean necesarias para el caso + `[DEFINIR]` | Eliminación segura | Coordinación |
| Auditoría y seguridad | `[DEFINIR]` | Eliminación segura o anonimización | Administrador |
| Autorizaciones de tratamiento | Mientras esté vigente + evidencia del plazo legal | Archivo restringido | Responsable de datos |
| Copias de seguridad | `[DEFINIR]` | Rotación y eliminación segura | Proveedor / técnico |

## Aprobación

La institución debe documentar quién aprobó cada plazo, la norma o necesidad que lo sustenta, la fecha de revisión y el método de eliminación. No se debe borrar información que deba conservarse por ley, investigación, auditoría o defensa de derechos.
