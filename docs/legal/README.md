# Paquete de cumplimiento de datos personales de SIGDE

Este directorio contiene los documentos y controles mínimos que deben completarse antes de publicar SIGDE para una institución real en Colombia.

## Bloqueos que requieren información de la institución

No se deben reemplazar con datos inventados:

- Representante legal y responsable designado para protección de datos.
- Correo institucional, correo de seguridad y correo para protección de datos.
- Correo de seguridad y soporte.
- Fecha de vigencia y versión aprobada.
- Lista real de proveedores: Vercel, Turso, proveedor de correo y cualquier almacenamiento de archivos.
- Países donde se almacenan o procesan los datos.
- Tabla de retención aprobada por la institución.
- Procedimiento institucional para autorizaciones de acudientes y estudiantes.

## Entregables

- `MATRIZ-TRATAMIENTO-DATOS.md`: inventario de datos, titulares, finalidades, acceso y riesgos.
- `TABLA-RETENCION-DATOS.md`: tiempos de conservación y disposición final que debe aprobar la institución.
- `PROCEDIMIENTO-DERECHOS-TITULARES.md`: flujo para consultas, reclamos, correcciones, supresión y revocatoria.
- `PROTOCOLO-INCIDENTES.md`: respuesta, evidencias, escalamiento y reporte de incidentes.
- `REGISTRO-ENCARGADOS.md`: proveedores y condiciones que deben verificarse y contratarse.

## Regla de publicación

La aplicación no debe publicarse como servicio institucional mientras existan campos entre corchetes en las políticas, no exista autorización verificable cuando corresponda, o la institución no haya aprobado estos documentos.
